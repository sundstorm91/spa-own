# 🧭 SPA Router from Scratch

Кастомная реализация одностраничного приложения (SPA) с нуля — роутер, состояние, компоненты и работа с DOM без использования фреймворков.

## 🛠️ Tech Stack

- **TypeScript / Vanilla JS** — чистая реализация
- **LocalStorage** — сохранение состояния
- **HashChange / PopState API** — навигация без перезагрузки

## 🎯 Что реализовано

| Компонент         | Описание                                                                     |
| ----------------- | ---------------------------------------------------------------------------- |
| **Router**        | Обработка URL (path + hash), динамические сегменты (`{id}`), редирект на 404 |
| **State**         | Хранение данных в localStorage, сохранение перед выгрузкой страницы          |
| **CreateElement** | Фабрика для создания DOM-элементов с классами, контентом и событиями         |
| **View**          | Базовый класс для всех компонентов (Header, Main, Footer, Index, Product)    |
| **App**           | Инициализация приложения, создание маршрутов, переключение контента          |

## 📂 Структура

src/
├── router/ # Роутер и конфиг путей
├── state/ # Управление состоянием (localStorage)
├── view/ # Компоненты (Header, Footer, Main, Index, Product)
├── utils/ # CreateElement, вспомогательные функции
└── app.js # Точка входа
